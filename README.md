# Axiom Blocks

Advanced Gutenberg blocks: post grid, tabs, accordion, content slider, table of contents, counter, testimonials, pricing table and more.

Repository: https://github.com/wpaxiom/axiom-blocks

## Blocks Included

### Advanced Section
Full-width container with background images, overlays, shape dividers, and entrance animations.

**Features:**
- Background color, image, or gradient
- Video background support
- Overlay with blend modes
- Shape dividers (top/bottom)
- Entrance animations
- Responsive controls

### Device Visibility
Wrapper block to show/hide content based on device type.

**Features:**
- Hide on mobile/tablet/desktop
- Clean wrapper with no extra markup

## Installation

### Method 1: Manual Installation
1. Download the plugin zip file
2. Go to WordPress Admin → Plugins → Add New
3. Click "Upload Plugin" and select the zip file
4. Click "Install Now" and then "Activate"

### Method 2: Development Setup

Axiom Blocks uses **PSR-4 autoloading** for its PHP classes under the `AxiomBlocks\` namespace (see `inc/`). The autoloader is generated by [Composer](https://getcomposer.org/), so Composer must be installed on your machine before the plugin will load.

#### Install Composer

**macOS / Linux:**

```bash
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
```

**Windows:**

Download and run the official installer from https://getcomposer.org/Composer-Setup.exe

Verify:

```bash
composer --version
```

#### Set up the plugin

1. Clone or download this repository to `wp-content/plugins/`
2. Navigate to the plugin directory: `cd axiom-blocks`
3. Install PHP dependencies: `composer install` (generates `vendor/autoload.php`)
4. Install JS dependencies: `npm install`
5. Build the assets: `npm run build`
6. Activate the plugin from WordPress admin

## Development

### Prerequisites
- Node.js 16+
- npm or yarn
- Composer
- WordPress 6.0+

### Available Scripts

```bash
# Start development mode with hot reload
npm start

# Build production version
npm run build

# Create plugin zip file
npm run plugin-zip

# Lint JavaScript
npm run lint:js

# Lint CSS
npm run lint:css

# Format code
npm run format
```
